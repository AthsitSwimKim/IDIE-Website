# assets-src — ไฟล์ต้นฉบับ ไม่ถูก build

โฟลเดอร์นี้อยู่นอก `public/` และนอก `src/` จึง **ไม่ถูกรวมเข้า bundle**
มีไว้เก็บไฟล์ต้นฉบับที่ลูกค้าส่งมา เพื่อให้ประมวลผลใหม่ได้โดยไม่ต้องขอซ้ำ

## reference-logos/

โลโก้ลูกค้าที่ได้รับมาโดยตรงจาก IDIE (คุณภาพดีกว่าที่ดึงจากเว็บเดิม)
ไฟล์ที่ใช้งานจริงอยู่ที่ `public/images/reference/<id>.webp` + `<id>-240.webp`

เมื่อได้โลโก้ใหม่จากลูกค้า: วางไฟล์ที่นี่ตั้งชื่อตาม id ใน `src/data/references.ts`
แล้วประมวลผลใหม่ให้ได้ผลลัพธ์ 480×320 (2x) และ 240×160 (1x) ตามมาตรฐานเดิม —
ตัดขอบขาว, normalize ตามพื้นที่, พื้นโปร่ง, วางกลางผืนผ้าใบ

## service-covers/

ภาพปกของหน้าบริการทั้งสี่ ที่ IDIE ส่งมา (ส.ค. 2026) ตั้งชื่อไฟล์ตาม `slug`
ใน `src/data/services.ts` เพื่อให้รู้ทันทีว่าไฟล์ไหนคู่กับหน้าไหน

ไฟล์ที่ใช้งานจริงอยู่ที่ `public/images/services/<slug>/cover.webp`
(บวก `cover-800.webp` เฉพาะรูปที่ต้นฉบับกว้างเกิน 800px)

วิธีประมวลผลใหม่ — แปลงเป็น WebP คุณภาพ 82 กว้างไม่เกิน 1600px
**ห้ามขยายเกินขนาดต้นฉบับ** เพราะได้ภาพเบลอที่ไฟล์ใหญ่ขึ้นโดยไม่ได้รายละเอียดเพิ่ม
ต้นฉบับสามในสี่ไฟล์กว้างเพียง 583–800px จึงมีไฟล์เดียวไม่มีคู่ 1x/2x

> ควรขอไฟล์ความละเอียดสูงกว่านี้จาก IDIE ถ้าต้องการให้คมบนจอ Retina —
> ที่กว้าง 583px (CCTV) ถือว่าเล็กสำหรับภาพที่แสดงกว้าง 560px บนเดสก์ท็อป
