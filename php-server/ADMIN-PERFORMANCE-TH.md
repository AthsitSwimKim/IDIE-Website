# แก้โหลดข้อมูลหลังบ้าน — ZIP 09
ZIP นี้รวมโค้ดล่าสุดจาก 06, 07, 08 และส่วนลดการรอโหลดแอดมิน อัปโหลดชุดเดียวได้

## สิ่งที่แก้
- ภาพรวมใช้ API สรุปหนึ่งคำขอ แทนโหลดข่าว ผลงาน อ้างอิง และยอดเข้าชมแยกสี่คำขอ
- สรุปเฉพาะตัวเลข ร่างที่ค้าง และหัวข้อข่าวล่าสุด 5 รายการ ไม่โหลดเนื้อหาข่าวเต็ม รูป หรือแกลเลอรีที่หน้าแรกไม่ใช้
- API อ่านข้อมูลปล่อยล็อกเซสชันหลังตรวจสิทธิ์ เพื่อให้คำขออื่นของบัญชีเดียวกันทำงานพร้อมกันได้
- ยังตรวจบัญชีและอายุเซสชันทุกคำขอ รวมถึงตรวจ CSRF สำหรับการเขียนข้อมูล ไม่มีการใส่ข้อมูลแอดมินในไฟล์ JSON สาธารณะ

## ติดตั้ง
1. อัปโหลด **09-faster-admin.zip** ลง **httpdocs** แล้ว Extract ทับ ไม่ต้องลบโฟลเดอร์รูป เอกสาร หรือ uploads เดิม
2. เปิด **/admin** แล้วกด Ctrl+F5
3. ถ้ายังไม่ได้เริ่มใช้ฐานข้อมูลตำแหน่งงาน ให้กด **อัปเดตข้อมูลหน้าเว็บไซต์** ในหน้าภาพรวม แล้วรอข้อความสำเร็จ

ใช้ Config เดิม ไม่ต้องตั้งรหัสผ่านใหม่หรือแจ้ง Support
ZIP ไม่มี private config ฐานข้อมูลจริง หรือรูป/เอกสารเดิมขนาดใหญ่
การลดคำขอและปล่อยล็อกช่วยส่วนที่โค้ดควบคุมได้ ความเร็วจริงยังขึ้นกับภาระงาน PHP/IIS/MariaDB ของโฮสติ้งในขณะนั้น
