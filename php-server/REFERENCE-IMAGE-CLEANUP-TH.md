# อัปเดตหน้าอ้างอิงและการลบไฟล์รูป — ZIP 10

ใช้ไฟล์ 10-reference-image-cleanup.zip ไฟล์เดียว รวมการแก้ไข ZIP 07, 08 และ 09 แล้ว

1. สำรองฐานข้อมูลและโฟลเดอร์ httpdocs/uploads ก่อนเริ่มใช้การลบรูปถาวร
2. อัปโหลด ZIP ลง httpdocs แล้ว Extract โดยเขียนทับไฟล์ที่ชื่อซ้ำ
3. เปิดเว็บและกด Ctrl + F5
4. ไม่ต้องแก้ config.php หรือเพิ่มตารางฐานข้อมูลสำหรับอัปเดตนี้

## สิ่งที่เปลี่ยน

- รายการอ้างอิงหน้างานกว้างเต็มคอนเทนเนอร์ รูปและเส้นคั่นชิดแนวหัวข้อ
- ลบข่าว ผลงาน หรืออ้างอิงหน้างานแล้ว ลบรูปอัปโหลดที่ไม่มีรายการอื่นใช้งาน
- เปลี่ยนรูปปก ลบรูปแกลเลอรี หรือเอารูปออกจากรายการ จะล้างรูปเก่าหลังบันทึกสำเร็จ
- เช็คการใช้งานข้ามข่าว ผลงาน แกลเลอรี และอ้างอิงหน้างาน รวมรายการร่างและข่าวตั้งเวลา
- เช็ครูปหลักและรูปย่อแยกกัน รูปที่ยังมีข้อมูลอ้างถึงจะยังอยู่
- การบันทึกที่ล้มเหลวและการลบที่ถูกปฏิเสธไม่ลบไฟล์รูป
- ลบเฉพาะชื่อไฟล์ที่ระบบอัปโหลดสร้างใน uploads ไม่ลบรูปเดิมใน images, documents, ไฟล์ส่วนตัว หรือ symlink
- กล่องยืนยันลบแจ้งเรื่องไฟล์รูปและการลบถาวรชัดเจน

## ขอบเขต

การล้างรูปทำงานกับรูปของรายการที่กำลังลบหรือแก้ไข ไม่กวาดไฟล์รูปค้างจากรายการที่ลบไปก่อนอัปเดต หรือรูปที่อัปโหลดแล้วไม่เคยบันทึกลงรายการ
โฮสต์ต้องอนุญาตให้ PHP ลบไฟล์ใน uploads ได้ หากอ่านฐานข้อมูลเพื่อตรวจการใช้งานรูปไม่ได้ ระบบเก็บรูปไว้เพื่อป้องกันลบรูปที่ยังใช้
หากลบไฟล์ไม่ได้จะเก็บไฟล์นั้นไว้และบันทึกเหตุขัดข้องใน PHP log; อัปเดตนี้ไม่มีงานล้างย้อนหลังอัตโนมัติ
ZIP ไม่รวม config.php, รูปจริง, ฐานข้อมูล หรือข้อมูลทดสอบ และไม่จำเป็นต้องสร้างแอดมินใหม่
การทดสอบการลบทั้งหมดทำบนชุดทดสอบ localhost; ไม่มีการลบข่าว ผลงาน หรือรูปบนเว็บจริงระหว่างทำงาน
