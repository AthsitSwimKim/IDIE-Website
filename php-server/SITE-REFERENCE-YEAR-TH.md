# เพิ่ม Year ให้รายการ Site Reference

ชุดอัปเดต `07-site-reference-year.zip` รวมหน้าแอดมิน หน้าเว็บ และโค้ดอัปเดต MariaDB พร้อมชุดแก้ความเร็วหน้าสาธารณะก่อนหน้านี้

1. อัปโหลด ZIP แล้ว Extract ลง `idindustrial.com/httpdocs` เลือกเขียนทับไฟล์เดิม ไม่ต้องลบเว็บเก่าหรือรูป
2. กด Ctrl+F5 เข้าแอดมิน → **ภาพรวม** → **อัปเดตข้อมูลหน้าเว็บไซต์** รอข้อความสำเร็จ ปุ่มนี้จะเพิ่มคอลัมน์ `year` ในตาราง `site_references` ถ้ายังไม่มี แล้วสร้างไฟล์ข้อมูลสาธารณะใหม่
3. ไป **รายการอ้างอิง** เปิดรายการที่ต้องการ ใส่ **ปี (Year)** เช่น `2026` แล้วบันทึก หน้าเว็บไซต์จะแสดง **YEAR: 2026** ใต้ Location ในภาษาอังกฤษ หรือ **ปี: 2026** ในภาษาไทย

ปีเป็นช่องไม่บังคับ ใช้ ค.ศ. ช่วง 1900–2200 ถ้าเว้นว่างจะไม่แสดงบรรทัดปี รายการเก่าจะมีปีว่างจนกว่าคุณจะใส่เอง ไม่มีการเดาปีหรือแทนค่าจากวันที่สร้างรายการ

การเพิ่มคอลัมน์เก็บ ID ชื่อ ลูกค้า สถานที่ ลำดับ สถานะ และรูปเดิมไว้ กดปุ่มอัปเดตซ้ำได้โดยไม่เพิ่มคอลัมน์ซ้ำ ถ้าเริ่มบันทึกรายการก่อนกดปุ่ม ระบบจะเพิ่มคอลัมน์ให้ก่อนบันทึกเช่นกัน

ถ้าขึ้นข้อความสิทธิ์ ALTER ให้ตรวจสิทธิ์ของบัญชีฐานข้อมูลใน RapidCloud ก่อนลองอีกครั้ง ไม่ต้องแก้ config.php หรือสร้างฐานข้อมูลใหม่ ชุด ZIP ไม่มีรหัสผ่าน config จริง หรือรูปเดิม

โค้ดของชุดนี้อยู่บน branch `Deploy` ฐานข้อมูลบน RapidCloud จะเปลี่ยนเมื่อคุณใช้ปุ่มหรือบันทึกรายการหลังอัปโหลดเท่านั้น
