# แก้หน้าลูกค้าอ้างอิง ผลงาน และข่าวสารโหลดข้อมูลช้า

ชุดอัปเดต: `06-fast-public-content.zip` แตกลงใน `idindustrial.com/httpdocs` และเลือกเขียนทับไฟล์เดิม ไม่ต้องลบเว็บเก่าหรือรูปเดิม

1. อัปโหลด ZIP เข้าโฟลเดอร์ `httpdocs` แล้ว Extract ไฟล์
2. รีเฟรชหน้าเว็บด้วย Ctrl+F5 และเข้าระบบแอดมิน ไปหน้า **ภาพรวม**
3. กด **อัปเดตข้อมูลหน้าเว็บไซต์** หนึ่งครั้ง รอข้อความ **อัปเดตข้อมูลหน้าเว็บไซต์แล้ว** จากนั้นเปิดหน้าลูกค้าอ้างอิง ผลงาน และข่าวสารเพื่อตรวจผล

หลังจากนั้น การบันทึกและลบรายการในแอดมินจะอัปเดตข้อมูลสาธารณะให้อัตโนมัติ ร่างและข่าวที่ยังไม่ถึงเวลาเผยแพร่จะไม่อยู่ในไฟล์สาธารณะ เมื่อข่าวถึงเวลาเผยแพร่ ผู้เข้าชมคนแรกจะเรียก API เพื่อสร้างไฟล์ใหม่ จากนั้นผู้เข้าชมจะอ่านไฟล์โดยตรง

ไฟล์ข้อมูลอยู่ใน `httpdocs/uploads/content-cache` ซึ่งมี `web.config` สำหรับให้ IIS เสิร์ฟเฉพาะ JSON หน้าเว็บจะอ่านไฟล์นี้โดยไม่รอ PHP/MariaDB หากปุ่มแจ้งว่าเขียนโฟลเดอร์ไม่ได้ ให้ตั้งสิทธิ์ Read/Write ของบัญชีเว็บไซต์สำหรับโฟลเดอร์ `uploads/content-cache` ผ่าน File Manager แบบเดียวกับโฟลเดอร์อัปโหลดรูป

ชุดนี้ไม่มี config.php รหัสผ่านฐานข้อมูล หรือไฟล์รูปเดิม ไม่ต้องแก้ `idie-private/config.php` ไม่ต้องสร้างแอดมินใหม่ และไม่ต้องใช้ CMD บน RapidCloud

ชุดอัปเดตยังรวมการอนุญาตโดเมนเว็บไซต์ทั้ง `www.idindustrial.com` และ `idindustrial.com` สำหรับคำขอเข้าสู่ระบบ โดยคงการตรวจ CSRF และปฏิเสธเว็บไซต์อื่นไว้

ข้อจำกัด: การเข้าสู่ระบบ บันทึกข้อมูล ส่งแบบฟอร์ม และการสร้างไฟล์ครั้งแรกยังต้องผ่าน PHP จึงอาจยังรอเซิร์ฟเวอร์เหมือนเดิม การปรับนี้ลดการรอของหน้าสาธารณะที่อ่านข้อมูลซึ่งเผยแพร่ไว้แล้ว ยังไม่ได้ยืนยันความเร็วบน RapidCloud จนกว่าจะอัปโหลดชุดแก้ไขและวัดผลจริง
