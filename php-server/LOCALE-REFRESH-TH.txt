ZIP 15 — รีเฟรชแล้วคงภาษาที่เลือก
เลือกไทยหรืออังกฤษแล้วรีเฟรชในแท็บเดิม จะคงภาษานั้นด้วย sessionStorage
เปิดเว็บในแท็บใหม่ที่เริ่มเซสชันใหม่ เริ่มภาษาอังกฤษ
หากเบราว์เซอร์ปิดกั้น storage ยังเปลี่ยนภาษาได้ แต่จำภาษาหลังรีเฟรชไม่ได้
มีเฉพาะไฟล์หน้าบ้านที่เปลี่ยนจาก ZIP 14: assets ที่ build ใหม่ และ index.html
อัปโหลด 15-keep-language-on-refresh.zip ลง httpdocs แล้ว Extract เขียนทับ จากนั้น Ctrl + F5
เก็บ assets เดิมไว้ ไม่ต้องแก้ PHP, Config หรือ Database
