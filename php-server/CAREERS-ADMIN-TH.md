# เพิ่มฐานข้อมูลตำแหน่งที่เปิดรับ — ZIP 08
ชุดนี้รวม API, assets และ index.html รุ่นล่าสุด รวมแก้โหลดข้อมูลหน้าสาธารณะและ Year ของอ้างอิงหน้างาน ไม่ต้องลง ZIP 06/07 ซ้ำ

1. อัปโหลด **08-careers-admin.zip** ไปที่ **httpdocs** แล้ว Extract ทับไฟล์เดิม ห้ามลบโฟลเดอร์รูป เอกสาร หรือ uploads เดิม
2. เข้า **/admin** แล้วกด **อัปเดตข้อมูลหน้าเว็บไซต์** รอข้อความสำเร็จ ปุ่มนี้สร้างตาราง **job_openings** และ **schema_migrations** และนำเข้าประกาศเดิม 2 ตำแหน่งครั้งเดียว
3. เปิดเมนู **ตำแหน่งที่เปิดรับ** เพื่อเพิ่ม/แก้ไข/ลบตำแหน่ง กรอกชื่อ ฝ่าย สถานที่ หน้าที่ และคุณสมบัติครบไทย/อังกฤษ เลือก **เผยแพร่ + เปิดรับสมัคร** เพื่อให้ขึ้นหน้าร่วมงาน
4. เปิด **/careers** ตรวจสอบ หากหน้าแอดมินยังเป็นรุ่นเดิมให้กด Ctrl+F5

- หน้าบ้านใช้รูปแบบการ์ดเดิมและสมัครทางอีเมลเดิม ไม่ต้องตั้ง SMTP เพิ่มสำหรับปุ่มนี้
- ร่างและตำแหน่งปิดรับไม่แสดงในข้อมูลสาธารณะ แต่เก็บไว้ในแอดมินได้
- ถ้าไม่มีตำแหน่งเปิดรับ จะแจ้งผู้เข้าชมเป็นไทย/อังกฤษ แยกจากกรณีโหลดล้มเหลวที่มีปุ่มลองใหม่
- การบันทึกและลบอัปเดตไฟล์ JSON สาธารณะอัตโนมัติ เพื่อลดการรอ PHP/MariaDB
- กดอัปเดตข้อมูลซ้ำไม่ทับการแก้ไข ไม่เปิดตำแหน่งที่ปิดไว้ และไม่สร้างตำแหน่งที่ลบแล้วกลับมา
- ZIP ไม่มี idie-private/config.php รหัสผ่าน ฐานข้อมูล หรือรูป/เอกสารเดิมขนาดใหญ่ ใช้ Config และข้อมูลเดิมได้
- ขั้นตอนนี้ไม่ต้องใช้ CMD บน RapidCloud บัญชี MariaDB ต้องมีสิทธิ์ CREATE ซึ่งเป็นสิทธิ์เดียวกับตอนติดตั้งระบบครั้งแรก
- การแก้ฐานข้อมูลจริงเกิดหลังอัปโหลดและกดปุ่มในข้อ 2 การทดสอบก่อนส่งใช้ฐานข้อมูลจำลองในเครื่อง
